# 2026 · ROUTE:ONE: 공차 최소화 자차 배차 추천

🏆 2026 K-DATA SCIENCE 해커톤 **창의상** (본선 26개 팀, 팀명 자만추)

## 문제와 접근

컨테이너 운송에서 공차 운행은 수익 없이 비용만 만드는 비효율 요인입니다. 자차와 용차를 함께 운영할 때 **자차 활용률을 높이는 것**이 원가 절감의 핵심인데, 기존 배차는 담당자의 경험에 의존합니다. 공차 패턴을 먼저 진단하고, 그 결과를 자차 우선 배차 추천에 반영하는 시스템을 만들었습니다.

1. **규칙 기반 공차 판정:** 같은 차량의 운송건을 시간순으로 연결해, 이전 하차지와 다음 상차지가 다르고 작업 간격이 12시간 이하인 구간을 공차로 추정합니다.
2. **용차 발생 예측:** 오더 속성, 자차 부하, 과거 용차 이력, 체이닝 가능성 등 30개 변수로 LightGBM 이진분류 모델을 만듭니다.
3. **신규 오더 판정과 자차 추천:** 저장된 모델과 룩업 테이블로 특징을 만들고, 대기 차량에 규칙 기반 점수를 매겨 추천 순위를 정합니다.

## 결과 (예선 데이터, 시간 분할 검증: 1–2월 학습 / 3월 검증)

| 항목 | 결과 |
| --- | --- |
| 공차 판정 규칙 | 재현율 95.9%, 정밀도 88.6% |
| 용차 발생 예측 (LightGBM) | ROC-AUC 0.845 (로지스틱 회귀·규칙 기반보다 우수) |
| 예측 확률 상위 20% | 실제 용차 발생 건의 47%를 포착 |

## 구성

```text
analysis/    01_eda.py              예선 EDA
             02_model.py            용차 발생 예측 모델 (LightGBM, 비교 모델)
             03_gongcha.py          규칙 기반 공차 판정
             04_score_new_order.py  신규 오더 판정·자차 점수
             05_app.py              신규 오더 판정 Flask 웹앱 (로컬 실행)
webapp/      ROUTE:ONE 배차 추천 웹 애플리케이션 (Flask + Leaflet)
             운송건 입력 → 추천 결과 → 지도에서 경로 확인 → 차량 비교·선택 → 배차 확정
notebooks/   dispatch_ai_demo_notebook_v3.ipynb  시연용 노트북
preprocess/  preprocess.R           지역·상하차지 표기 통일, 이상치·결측 처리
```

`webapp/`의 자세한 실행 방법과 구조는 [webapp/README.md](./webapp/README.md)를 참고하세요.

## 포함되지 않은 것

- 기업이 제공한 운송 데이터(마스킹 샘플)와 거기서 만든 중간 파일, 학습된 모델 파일
- 위 파일이 없으면 `analysis/`와 `webapp/`은 바로 실행되지 않습니다. 코드 구조와 방법을 확인하는 용도입니다.
- 지도는 OpenStreetMap 타일과 OSRM 공개 서버를 사용합니다.
