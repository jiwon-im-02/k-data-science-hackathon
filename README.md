# K-DATA SCIENCE 해커톤 코드 모음

과학기술정보통신부·한국연구재단 주최 **K-DATA SCIENCE 해커톤**(2024–2026)에 팀으로 참가하며 작성한 코드를 연도별로 정리한 저장소입니다. 세 번 모두 본선에 진출해 **창의상**을 받았습니다.

| 연도 | 주제 | 핵심 기법 | 폴더 |
| --- | --- | --- | --- |
| 2024 | 사회적 고립 해소를 위한 네트워크 기반 감정 분석 | KR-BERT 임베딩, PCA, TF-IDF, Soft Cosine 유사도 그래프 | [2024](./2024) |
| 2025 | AI 기반 자필 서명 진위 판별 (AegisSign) | Siamese Network (CNN·BiLSTM / ResNet18), FastAPI, React | [2025](./2025) |
| 2026 | 공차 최소화 자차 배차 추천 (ROUTE:ONE) | 규칙 기반 공차 판정, LightGBM, Flask, Leaflet 지도 | [2026](./2026) |

## 구성

```text
2024/   preliminary/  임베딩·유사도 행렬·클러스터링 노트북
        finals/       상담 데이터 전처리, 임베딩 PCA·k-means
2025/   notebooks/    전처리, Siamese 모델 실험
        backend/      FastAPI 검증 서버
        web/          React + TypeScript 웹 화면
2026/   analysis/     EDA, 용차 예측 모델, 공차 판정, 신규 오더 판정
        webapp/       ROUTE:ONE 배차 추천 웹 애플리케이션
        notebooks/    시연용 노트북
        preprocess/   데이터 전처리(R)
```

## 데이터 안내

대회 데이터는 **이 저장소에 포함하지 않았습니다.** AI Hub 데이터는 각 데이터의 이용 약관에 따라 직접 내려받아야 하고, 2026년 데이터는 기업이 대회용으로 제공한 마스킹 샘플이라 재배포하지 않습니다. 따라서 코드는 **구조와 방법을 보여 주기 위한 것**이며, 데이터를 준비하고 경로를 맞춰야 실행됩니다. 노트북은 출력 셀을 모두 지운 상태이고, 파일 경로는 `./`로 바꿔 두었습니다.
